# Third-party fonts

The template (meme) editor bundles the fonts below. Each is licensed under the
SIL Open Font License, Version 1.1 (OFL), whose full text is shipped alongside
the font files in this directory. The `.woff2` files here are subsetted (Latin
range) copies of the upstream releases.

| Font | File | Copyright | License | Source |
| --- | --- | --- | --- | --- |
| Anton | `anton.woff2` | Copyright 2020 The Anton Project Authors | OFL 1.1 (`Anton-OFL.txt`) | https://github.com/googlefonts/AntonFont |
| Comic Neue | `comic-neue.woff2` | Copyright 2014 The Comic Neue Project Authors | OFL 1.1 (`ComicNeue-OFL.txt`) | https://github.com/crozynski/comicneue |
| Jost* | `jost.woff2` | Copyright 2020 The Jost Project Authors | OFL 1.1 (`Jost-OFL.txt`) | https://github.com/indestructible-type/Jost |

The OFL permits bundling and redistribution provided the license and copyright
notice travel with the font — which is why the `*-OFL.txt` files live next to the
`.woff2` files and are served as static assets.
